
# 🧩 Crossword Quest

A fun and interactive browser-based crossword puzzle game built with HTML, CSS, and JavaScript. Solve word clues, complete puzzles, earn points, and challenge yourself to improve your performance.

## ✨ Features

- 🧩 Interactive crossword puzzle grid
- 🔤 Across and Down word clues
- 💡 Hint system to reveal a letter
- 👀 Reveal the complete selected word
- ✅ Check answers and identify incorrect letters
- 🧹 Clear the selected word
- ⏱️ Live game timer
- 🏆 Score tracking and completion bonus
- 📊 Puzzle completion progress
- 🔄 Replay puzzles and start a new round
- 📱 Responsive, browser-based gameplay

## 🎮 How to Play

1. Open the game in your browser.
2. Select an Across or Down clue.
3. Enter letters into the crossword grid.
4. Use the arrow keys to navigate between cells.
5. Click **Check** to check your answers.
6. Use **Hint** when you need help.
7. Use **Reveal** to reveal the selected word.
8. Complete the puzzle to earn points and finish the round.

## 🚀 Getting Started

### Run Locally

1. Clone this repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Open the project folder in Visual Studio Code.

3. Make sure the project contains these files:

   ```text
   crossword-quest/
   ├── index.html
   ├── style.css
   ├── script.js
   └── README.md
   ```

4. Open `index.html` in your browser, or run it using the Live Server extension in VS Code.

No backend or database is required.
